# Turkish Real Estate Price Prediction 🏠🇹🇷

Комплексный проект машинного обучения для автоматизированной оценки стоимости недвижимости в различных городах Турции. Платформа способна прогнозировать цены как для **покупки/продажи**, так и для **аренды** объектов на основе их характеристик (площадь, возраст здания, тип отопления, город и район).

## 🚀 Этапы реализации проекта

Проект был реализован в 4 основных этапа:

1. **Разведочный анализ данных (EDA):** Изучение распределения цен в разных городах Турции, поиск аномалий и оценка влияния характеристик на итоговую стоимость.

2. **Предобработка данных:** Очистка от экстремальных выбросов по цене и площади, обработка пропусков, конвертация мультивалютных цен в единую валюту (турецкую лиру — TRY).

3. **Обучение и выбор модели:** На начальном этапе проводилось сравнение трех различных алгоритмов: **Линейной регрессии (Linear Regression)**, **Случайного леса (Random Forest)** и **CatBoost Regressor**. По результатам оценки метрик качества лучшей моделью был выбран CatBoost.

4. **Создание приложения:** Упаковка готовых моделей в REST API с использованием **FastAPI** и разработка пользовательского веб-интерфейса на **Streamlit**.

## 📌 Архитектурные особенности

* **Двойная архитектура:** Разработаны две независимые модели CatBoostRegressor — отдельно для рынка купли-продажи (где цены достигают сотен миллионов) и для рынка аренды.

* **Продвинутая обработка категорий:** Отказ от классического One-Hot Encoding. Итоговая модель использует нативный механизм обработки текстовых признаков `cat_features` (CatBoost), что позволило алгоритму эффективнее улавливать скрытые зависимости по городам и районам.

* **Логарифмирование таргета:** Для сглаживания выбросов целевая переменная логарифмируется при обучении (`np.log1p`), а при выдаче результата пользователю возвращается в реальные деньги через `np.expm1()`.

## 📁 Структура репозитория

### Исходный код и аналитика (Jupyter)

* `Первая работа.ipynb` — Основной ноутбук проекта. Содержит шаги 1-3: полноценный EDA, пайплайн очистки данных, сравнение моделей (Linear Regression, Random Forest, CatBoost) и итоговое обучение лучшего алгоритма.

* `Тестирование модели.ipynb` — Копия основного ноутбука, дополненная блоком валидации. Включает пайплайн применения модели на новых, ранее не виданных алгоритмом отложенных данных (на примере файла с 20 строками) и расчет реальных бизнес-метрик.

### Приложения (Инференс)

* `main.py` — Backend-часть приложения, реализованная на базе **FastAPI**. Отвечает за прием данных и маршрутизацию запросов к моделям.

* `app.py` — Frontend-часть, интерактивное веб-приложение на **Streamlit** для удобного взаимодействия с моделями.

### Артефакты моделей

* `catboost_model.pkl` — Сохраненные веса обученной модели.

* `model_columns.pkl` — Структура признаков для строгого выравнивания данных при поступлении новых запросов.

* `scaler.pkl` — Артефакты масштабирования числовых признаков.

### Данные и окружение

* `test_real_estate_samples.csv` — Тестовая выборка новых объявлений для проверки работы пайплайна инференса.

* `result_real_estate_samples.csv` — Итоговый файл с результатами работы алгоритма (добавлена колонка `predicted_price`).

* `requirements.txt` — Зависимости и библиотеки, необходимые для работы проекта.

## 📊 Результаты и метрики

Модели прошли оценку на отложенной тестовой выборке с конвертацией логарифмических ответов обратно в турецкие лиры (TRY):

* **Модель продаж (CatBoost):** Коэффициент детерминации $R^2 = 0.68$. Алгоритм успешно объясняет 68% дисперсии в сегменте с колоссальной волатильностью цен (от 50 тыс. до 100 млн TRY).

* **Модель аренды (CatBoost):** Средняя абсолютная ошибка (MAE) составила **3367 TRY**. Модель демонстрирует высокую точность на массовом сегменте съемного жилья. Значение $R^2$ находится в положительной зоне ($0.09$), что является сильным результатом для выборки из 10 объектов с экстремальными ценовыми выбросами.

## 💻 Инструкция по запуску

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/mamba578/first_work_four_kurs
   cd test
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запуск Backend (FastAPI):

   ```bash
   uvicorn main:app --reload
   ```

4. Запуск Frontend (Streamlit) в новом окне терминала:

   ```bash
   streamlit run app.py
   ```
